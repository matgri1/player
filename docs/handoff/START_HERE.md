## 1. Что за проект

**Kuy** (читается «Куй», от города **Quy Nhon / Куйньон**, Вьетнам) — экосистема услуг для
иностранцев в Куйньоне. Основная аудитория сайта — **американцы**, дальше русскоязычные и вьетнамцы.

Услуги:
- **Визараны** — поездки на границу с Лаосом (КПП Бо И) или Камбоджей (КПП Ле Тхань) за новым въездом.
  Самая важная услуга. Уже работает отдельная система **QUY Travel** (бот @quytravel_bot + сайт).
- **Обмен валют** (USD/EUR/RUB → VND).
- **Русская домашняя еда** (пельмени, сырники, борщ и т.д.).
- **Туры** по Куйньону (Ки Ко, Эо Зио, башни Чам, острова).
- **Маркетплейс** — позже.

Бренд: на сайте сейчас «Kuy», у действующей системы визаранов — «QUY».
Владелец ещё не решил, переименовывать ли сайт в QUY (открытый вопрос).

## 2. Что сделано (состояние на момент передачи)

### Сайт `kuy/` (статический, EN/RU/VI)
- Главная в «американском» стиле: светлый фон, белые карточки, синие кнопки, понятные тексты,
  анимированный пример чата, часы Куйньона с разницей во времени, FAQ, плавающая кнопка «Message us».
- **Визараны** (`visa/`), 4 вкладки:
  - *Обзор*: маршруты, живое расписание и цены виз из публичного API QUY Travel, процесс записи, QUY Club.
  - *Записаться*: форма из 5 шагов (направление → дата → пассажиры → контакты → проверка),
    повторяет процесс записи QUY Travel, с подсказками для американцев.
    Сверху анимация: **слипбас едет из Куйньона к границе** по мере заполнения формы, вьетнамский пейзаж,
    рассвет → день, навстречу едут байки (собака за рулём, 5 человек на байке, курицы, холодильник, шарики).
  - *Когда ехать?*: калькулятор срока пребывания (штамп 45 / e-visa 90 / своё), дни до конца,
    рейсы, на которые успеваешь, напоминание (Google Календарь; Telegram-бот — пусто, будет тестовый).
  - *Чек-лист*: что взять с собой (тестовая версия, потом переносится в Telegram-бота).
- **Обмен** — калькулятор, **Еда** — меню с корзиной, **Пригласи друга** — реферальная программа Kuy.
- Все настройки — в начале `kuy/app.js` (см. `kuy/README.md`).

### Сервер `server/` (Node.js + Express + PostgreSQL, как у QUY Travel)
- Отдаёт сайт, принимает заявки с формы `POST /api/visa/requests`.
- **Админ-панель `/admin`** (RU): сводка, заявки (фильтры, статусы, заметки, история),
  **группы** (кто едет в одну дату на одну границу), выгрузка CSV, уведомление в Telegram.
- Проверено в тестовой среде (временная PostgreSQL): полный путь «клиент записался → админ увидел,
  поменял статус → группа посчиталась → CSV», защита от спама/CSRF/подбора пароля. `npm test` — 8/8.
- Если сайт открыт **без** сервера (GitHub Pages), форма сама переходит на отправку заявки
  менеджеру в Telegram (@quynhon_visarun) — ничего не ломается.
- Подробно: `server/README.md`.

## 4. Правила работы с сервером (важно)

1. **Сначала только смотреть.** Перед любыми изменениями — разведка (read-only) и отчёт владельцу.
2. **Действующую систему QUY Travel не трогать**: её код, процессы, базу, бота, nginx-блок.
   - Не запускать вторую копию бота с тем же токеном (конфликт polling — бот перестанет работать).
   - Не перезапускать их сервисы без явного разрешения.
3. **Любое изменение — после согласия владельца**, с резервной копией (`cp file file.bak-ДАТА`)
   и проверкой `nginx -t` перед reload.
4. **Секреты** (`.env`, пароли, токены) — только на сервере, `chmod 600`, никогда в чат/GitHub.
5. Kuy ставится **рядом**: отдельная папка, отдельный пользователь ОС, отдельная база,
   отдельный порт (3100), отдельный nginx server-блок (предлагаем поддомен
   `kuy.82-27-201-63.nip.io`, позже — свой домен).
