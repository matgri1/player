# Kuy — сайт сервисов в Куйньоне (Quy Nhon), Вьетнам

Статический сайт (HTML + CSS + JS, без сборки). Основная аудитория — американцы,
есть русская и вьетнамская версии. Язык по умолчанию английский, `?lang=ru|vi` открывает нужный.

## Страницы
| Путь | Что это |
|---|---|
| `index.html` + `home.js` | Главная: услуги, «Как это работает», FAQ, реферальный блок, контакты |
| `visa/index.html` | Визараны: вкладки «Обзор», «Записаться» (форма + слипбас), «Когда ехать?», «Чек-лист» |
| `visa/visa.js` | Живое расписание и цены виз из API QUY Travel (публичные данные) |
| `visa/book.js` | Форма записи (5 шагов), отправка на сервер Kuy или в Telegram |
| `visa/when.js` | Калькулятор срока пребывания + рейсы до дедлайна + напоминания |
| `visa/checklist.js` | Чек-лист «что взять» (тестовая версия, потом в бота) |
| `exchange/` | Калькулятор обмена валют (курсы — образец, правятся в `exchange.js`) |
| `food/` | Меню русской кухни с корзиной → заказ в мессенджер (картинки — заглушки SVG) |
| `refer/` | Реферальная программа Kuy (коды выдаются вручную через WhatsApp/Telegram) |

## Где что настраивать
Всё в начале `app.js`:
- `CONTACTS` — WhatsApp / Telegram / Messenger / Zalo (**пока пустые**)
- `PRIMARY_CHANNEL` — главный мессенджер по языку (ru → Telegram, остальные → WhatsApp)
- `REFERRAL`, `SITE_URL` — бонусы реферальной программы и адрес для ссылок
- `VISA_APP` — система QUY Travel (сайт, API, бот, менеджер)
- `SITE_API` — адрес API сервера Kuy (`/api`)
- `REMINDER_BOT` — тестовый бот напоминаний о визе (**пока пустой**)
- `SUBSITES` — куда ведут кнопки услуг (можно заменить на внешние сайты)

Тексты — `i18n.js` (en/ru/vi, ключи = атрибуты `data-i18n`).

## Запуск
Локально: `python3 -m http.server` в этой папке. С сервером: см. `../server/README.md`.
