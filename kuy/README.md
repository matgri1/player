# Kuy — сайт экосистемы сервисов в Куйньоне

Статический сайт (HTML + CSS + JS, без сборки).

- `index.html` — разметка страницы
- `styles.css` — стили
- `i18n.js` — все тексты на EN / RU / VI (ключи совпадают с `data-i18n` в HTML)
- `app.js` — переключение языка, мобильное меню, анимации

Язык по умолчанию — английский. Выбор сохраняется в браузере; можно открыть сразу нужный язык: `?lang=ru`, `?lang=vi`.

Локальный запуск: `python3 -m http.server` в этой папке → http://localhost:8000
